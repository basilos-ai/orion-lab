# 聊天偏好与未发送内容的离开保护

回答模型和调用范围通过浏览器键 `orion-chat-preferences-v1` 作为一对设置保存，刷新后恢复当前最后使用的选择。它只包含 mode / scope，不保存正文、图片、文件路径、设备身份或模型凭据；原会话、旧历史和 Auto 决策偏好存储键保持。

恢复时校验模型闭集与范围值。有效的 9B / 仅本地、DeepSeek / 允许云端等组合保持原样；无效模型回到 Auto，无效配置或存储读取失败按仅本地处理，避免错误数据扩大调用范围。没有任何已保存偏好的新浏览器仍使用原来的 Auto / 允许云端默认值。存储写入失败会在页面提示无法在刷新后保留选择。

恢复偏好本身不会发送消息、创建模型任务、加载或切换模型。图片、项目工具、授权和仅本地禁云端等原有能力约束继续在 UI 与服务端校验；恢复选择不代表对应模型已经就绪。

未发送草稿和被阻断原文继续只存当前页面内存，不新增正文持久化。离开检查覆盖当前编辑器及切出会话的文字、图片、已选文件，也覆盖当前活动任务。当前编辑器优先于该会话在 Map 中的旧快照，避免清空草稿后仍反复提示。

在已交互的页面执行正常刷新或导航，存在上述未发送内容时触发浏览器原生离开确认。取消离开后，页面和其他会话的草稿保持；明确确认离开后放弃这些内存内容，刷新不能恢复。不恢复侧栏“草稿”分组，不自动发送，也不把未审核内容写入服务端记录。浏览器原生提示文案由浏览器决定，系统强制终止或移动端后台回收不保证触发 beforeunload。

回归包括桌面与手机上的模型 / 范围刷新、云端组合恢复、无效组合不升级范围、不自动加载或提交、切出草稿后真实刷新提醒、取消后恢复输入、清空后不再提示，以及纯逻辑对文字 / 图片 / 文件和旧快照的检查。
