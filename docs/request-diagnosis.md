# 单次请求 AI 排障

打开聊天的「执行详情 → 本轮 → AI 排障」，可在发送前查看依据、输入问题。默认使用所选聊天回执，分析用独立的一次本地 9B 文本请求，沿用输入审核。历史聊天原文和附件不加入诊断提示。分析结果只保留在当前面板。

核对限额、发布版本或网关失败模式时，在已登录 AI Gateway CLI 的管理电脑运行以下命令。请填写执行详情里的网关请求 ID。

```sh
python scripts/export-request-evidence.py --workspace <工作区ID> --request <网关请求ID> --output request.json --cli <AI-Gateway-CLI可执行文件路径>
```

可用 `--cli` 指定 CLI 路径、`--profile` 指定登录配置。默认查最近 10 页用量，可用 `--pages` 调整。工具验证工作区读权限，按工作区和请求 ID 精确匹配，获取该请求实际使用的发布快照，导出路由、状态、用量与策略字段。没有记录的字段留空。将 JSON 导入排障面板后，核对显示的请求 ID，再点击「分析请求」。导入文件作为单独的数据来源，不与当前聊天回执拼接。

模型名称不同不能单独证明直连。判断某条限额是否适用，需要同一请求的调用方式、作用范围和当时发布的策略绑定。若发布快照只提供策略名称或缺少绑定明细，应补查管理端记录。
