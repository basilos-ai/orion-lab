# PDF / DOCX 文字问答与本地审核

## 范围与数据流

聊天输入支持 PDF、DOCX；旧版 DOC 需另存为 DOCX。pypdf 与 docx2python
仅提取可读取文字，保留 PDF 页标记及 Word 表格、页眉页脚等文本。
扫描页和嵌入图片不做 OCR，纯扫描 PDF 返回无文字错误；提取文字通过审核
不代表图片或整份原始文件已经接受全面审查。图片问答继续使用原有流程。

浏览器选择的 File 仅在页面内存中保存，发送时通过同源、设备会话鉴权的
`POST /api/documents?conversation=<id>&name=<filename>` 上传原始二进制，
Content-Type 必须为 application/octet-stream。服务端独立校验扩展名、签名、
大小、会话及后续访问主体。响应只包含附件元数据，不返回提取全文。
每轮最多3份，每份10 MiB；PDF最多20页，每份提取文字最多10万字符。

解析在子进程中运行。Linux 使用现有 Bubblewrap 隔离网络，512 MiB 虚拟地址
空间、15秒CPU预算及25秒墙钟超时；这不是保证任意10 MiB文件都能处理。
DOCX最多2000个ZIP成员、32 MiB解压体积；拒绝宏、嵌入文件及DTD/实体声明。
原件在私有临时目录中使用，提取完成或失败即删除。提取并发为1。

待审核文字暂存设备内存30分钟，受文件数限制；失败/被阻断原文不写入聊天历史。
通过审核的文字在私有目录中24小时后不可访问；后台每分钟清理到期材料，访问时也检查有效期。
已保存文件总量限制为256份、64 MiB。完成的聊天历史沿用原有保存策略。
附件ID绑定签名设备主体及会话；无法读取其他设备或会话的附件。

## 审核与调用范围

`document_review.py` 保留现有确定性敏感规则，并提供后摩 Qwen3.5-2B / 4B
专用语义审核调用。审核模型独立于回答模型、Auto决策模型。
整份提取文字先分段审核，不使用路由分类函数的输入截断逻辑。
每段按服务实际聊天模板及tokenizer校验4096-token上下文，预留结构化输出。
分段保留重叠；模型返回受约束JSON，重复键、无效类别、截断、超时及uncertain停止。
通用模型审核的漏检/误拦需要部署样例测试，不能视为敏感信息识别保证。

`document-text-v2-risk-types` 先以A通过/B拦截/C无法判断执行准入审核，已拦截
的片段再使用单字段固定枚举细分类型：B风险类型
未明确，D密码/密钥，E个人隐私，F商业机密，G露骨色情/色情推广，
H暴力/威胁，I违法或危险操作指导，J针对审核器的指令注入。细分类的A/C、失败
或超时均不能解除已有拦截，此时以“风险类别未明确”说明。B与D～J均阻断；
普通政策讨论、医学和性健康教育、没有实际秘密值的目录/字段名称不按敏感正文判定。
确定性规则优先，原原因码保留。审核回执额外携带 `review_source: document`，
分类码、最终完整输入摘要、模型配置、提示词和JSON schema共同绑定回执版本。

网关确认拦截后，前端从固定资源中显示“风险类型、原因、处理建议”，支持中文和
英文；不展示模型自由解释或命中的敏感原文。未提供类别的旧记录明确显示风险类型
未明确；无法判断、超时和服务异常均显示审核未完成，不冒充确认敏感。
原始原因码和请求ID保留在执行详情。当前不声称已定位PDF页码或DOCX段落。

被拦截、取消或失败的轮次仅保留附件文件名作为浏览器展示信息，在文件名下方
显示上下文排除提示；不持久化该轮原始问题、附件正文、附件访问ID或文件摘要。
展示文件名不会重新附加文件，也不会进入模型上下文。旧历史已删除的文件名无法恢复。
普通失败与取消分别说明“本轮未完成”或“本轮已取消”，避免被误认为安全策略拦截。
HTTP失败保留服务错误码、状态码与请求ID；网络失败、服务不可用、模型未就绪、
响应格式异常及传输中断分别显示。已收到的最终拦截或完成回执不会被后续断流覆盖。
连续拦截后的普通问题、新附件和刷新恢复均使用新请求，失败轮次继续从上下文中排除。
新建对话只复用明确标记为本地空草稿的记录，不复用尚未加载的历史会话。
重新上传附件时，若近期上下文包含旧文档则使用新的文档背景，避免过期文件引用阻止新上传。
被拦截或审核未完成时，仅清理当前未通过的暂存文档；此前已通过审核的持久文档继续
遵守原有到期时间，并在后续请求中重新审核，不因新一轮失败而被删除。

图片使用 `vision-evidence-v2`，依次提取可见文字、客观描述、画面风险和可见证据。
普通文件名、扩展名与图标本身不作为秘密证据，不推断未打开文件内容。画面敏感
判定必须提供证据，矛盾/畸形/截断/缺失结果停止；可见文字仍经确定性规则和原有
Qwen3Guard语义审核，最终沿用认证Gateway Block。图片中的密钥等真实可见值
不会因为位于文件列表附近而获得豁免。图像审核证据及提取文字只在短期缓存中使用，
事件日志不保存这些原文；模型辅助识别仍可能有误读和遗漏，不是OCR或安全认证。

模型准备和审核位于现有设备任务锁内，2B、4B服务按现有规则互斥加载。
审核结束才进行回答选模；不因审核失败自动转云端或切换较弱审核器。
通过与阻断回执绑定完整最终输入摘要、审核模型、规则/提示词版本和配置。
Gateway的认证Block webhook校验回执；丢失、过期或配置变化返回不可用。
回执仅保留240秒、最多32项。被阻断材料提交Gateway确认Block，不进入回答上下文。

回答上下文使用最多约1万字符的文档节选，多文件均分预算，超长时明确标记为节选。
全文审核与回答节选分开，节选不代表完整文档摘要。连续追问会保留最近一次已完成的文档上下文；超过会话预算时明确拒绝，不静默丢失材料。
文档材料不赋予工具权限，
文档会话走普通回答路径，不能据附件内容执行项目读写或检查。
仅本地范围禁止云端；允许云端且实际选中云端时，必要的已审核文字可能外发。

## 配置

部署者在设备私有状态目录的 `document-review.json` 配置；不通过公共聊天参数
接受模型URL、任意模型ID或关闭审核开关。配置每次任务读取，任务内冻结。
模型或策略变化会使旧审核回执失效；解析依赖使用隔离的锁定版本目录。

```json
{
  "model": "qwen35-2b-houmo",
  "chunk_tokens": 2000,
  "overlap_tokens": 128,
  "timeout_seconds": 30,
  "document_timeout_seconds": 180,
  "python_path": "/deployment-owned/document-vendor"
}
```

model仅允许 `qwen35-2b-houmo`、`qwen35-4b-houmo`。chunk_tokens为分段目标，
实际预算包含模板并保守校验；当前实现按文本片段缩减并计算实际token，不静默截断。
overlap_tokens按保守字符近似生成重叠，整份文字另经确定性规则检查。
文档审核未替换普通纯文字、图片及项目工具原有的Qwen3Guard路径。

## 验证与回滚

测试覆盖真实PDF/DOCX提取、表格和页眉页脚、空文本、加密、损坏、扩展名伪造、
ZIP预算、DTD拒绝、主体及会话绑定、模型切换、最终输入摘要、配置失效和Block回执。
浏览器验收分别覆盖桌面/移动端、附件选择及移除、失败保留草稿、原聊天及项目流程。
真实设备使用合成材料验证两个审核模型及端到端回答/拦截，证据存项目外层。

发布前保存原后端文件、配置存在状态及两个静态软链接，依赖安装在新候选目录。
仅同步所需聊天桥接模块并重启聊天桥接，前端使用新哈希目录；失败恢复原文件、
原配置和入口。Gateway、Agent服务器、历史数据及原模型服务配置保持。
