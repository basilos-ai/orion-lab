# 用户聊天工作区

## 刷新与会话状态保留（2026-10-30）

回答模型和调用范围现在作为浏览器偏好保留，刷新不会重置已选择的“仅本地”。离开保护检查全部会话的未发送内容，取消离开后可继续编辑；正文仍仅存内存，确认离开后不可恢复，不恢复侧栏草稿分组。完整规则、校验和边界见[聊天状态说明](chat-state-preservation.md)。下文历史记录中的原刷新行为已由此更新。

## 快速体验与每轮反馈（2026-10-22）

首页新增“体验自动选模 / 体验安全保护”，共用三个体验页：自动选模、输入拦截、输出保护自检。简单计算与多步计算分别调用真实 `/api/chat`，Auto、仅本地、单条固定材料，不提交会话/项目/文件/原草稿；输入体验手动指定本地4B，提交明确虚构的凭据材料，真实保护回执确认阻断才显示成功。选模结果来自当前回执，不硬编码模型或宣称分类器已经执行。体验不入会话历史、不改当前设置；运行时暂停原输入框发送，关闭/停止会中止体验请求，服务端门锁继续约束并发。

输出体验 POST `/api/agent/experiences/output`，在已有设备会话、同源及内部身份校验后，使用项目运行时实际的 `AnswerStream` 检查器对固定正常文本和跨片段虚构凭据做自检。调用方不能提供候选内容、模型、工具或策略配置。回执明确合成输出、无模型调用、只覆盖项目敏感模式，不冒充真实模型输出或完整语义审核；不完整或失败回执不显示拦截成功。

每轮回答展示模型执行回执、选模依据与来源、输入结果和输出范围。推荐模型不等于实际执行；输入已阻断/审核未完成显示未调用回答模型。普通聊天明确未启用输出审核，项目回答和工具结果只声明已执行的敏感检查；新增方向化 protection 事件区分输入、工具输入、工具输出和回答输出。缺少证据的旧任务显示未记录。完成的普通聊天在服务端保存有界反馈元数据，恢复对话时继续显示，不将反馈放入模型上下文。

## 任务示例与隐私说明（2026-10-22）

新对话保留两张任务卡：会议记录整理为结论、负责人/期限待办和待确认事项；订单平均金额代码分析包含错误现象及空输入边界。材料明确标为虚构、可替换，点击仅填入并聚焦输入框，已有文字草稿时提示先处理草稿，运行中不可填入。

隐私与安全入口移到输入框模型/调用范围按钮旁，移动端保留带可访问名称的盾牌按钮。点击打开本地说明弹窗，不提交问题、不调用模型、不改变调用范围或草稿；关闭后恢复入口焦点。弹窗随当前范围、回答模型和图片上下文区分实际可能的回答去向，并展示当前输入审核服务的连接状态。

规则内容依据 `services/o6n-bridge/{bridge,controlled_bridge,input_policy,agent_extension}.py`、`packages/{agent-runtime,tool-runner}/src/index.ts`、`apps/agent-server/src/conversations.ts` 及前端 `lib/stream.ts` 维护：浏览器到设备、设备网关与本地输入审核、获准的本地/DeepSeek 回答路径、图片仅本地、项目文件/工具结果可能用于云端上下文、逐项操作审批、浏览器和服务端记录、内存草稿与阻断原文边界。明确“本地”是服务运行设备，输入匹配拦截而非自动脱敏放行，未承诺全面识别、语义输出审核或云端零留存。后端规则变更须同步此说明。

## 当前入口：统一 Agent（2026-10-22）

Ask 切换已移除，新会话为 Agent / Auto。无项目直接聊天；项目工具默认只读，修改与检查逐项审批。全部回答模型与图片保留；手动对话模型遇到项目操作会提示切换，不自动换模。仅本地禁止云端，任务内锁模保持。

详见[能力、权限、历史兼容与启动](unified-agent.md)。下方带旧日期或旧模式名的段落为历史变更记录，当前行为以本节为准。

## Auto决策模型选择

沿用Harness PromptInput，回答模型菜单仅在Auto时展示独立决策单选组：Laya、后摩2B、后摩4B。输入区下方显示所选决策模型，回答归属仍显示真正回答者。决策模型与调用范围独立；仅本地时DeepSeek选项禁用，后端也拒绝手动云端派发。

单选组使用现有Popover／手机Dialog、主题和滚动边界，保留radio方向键与Esc焦点恢复。选择不发送消息、不加载模型或清空草稿；生成中禁用，只影响下一条任务。首次加载显示准备状态，成功不展开技术数据，失败说明回退，详情保留实际引擎与是否执行。

新界面默认2B，独立偏好键保存选择；内存草稿与每轮快照记录引擎，恢复失败草稿时恢复当轮设置。旧任务无字段按Laya解释。切换Ask／Agent、项目或手动回答不重置决策偏好。仅本地工具任务只有9B时说明跳过判决，不声称引擎已经执行。

聊天与Pi共用一个消息时间线、会话列表和输入框。主视图保留提问、回答、必要等待、确认、阻断及失败信息；正常完成不展开审核、选模判决、工具参数、Run ID或桥接说明。模型标识保留作回答归属，耗时、审核、工具及运行标识由用户主动打开详情查看。普通问答和Pi均以回答为主，代码复制与宽表格阅读保留。

## 输入框来源

实际使用用户指定Web UI Harness中的PromptInput、Body、Header、Footer、Tools、Submit和Textarea，而不是同名自绘适配或替代库。源码放在`packages/harness-ui`，项目所有者已于2026-10-20明确授权MIT再分发。原始及采用文件哈希见component-provenance.json。必要UI控件跟随源组件，未复制Workbench业务模块或引入开发机绝对路径。

宿主只负责草稿、模式/模型/范围、授权项目/文件与发送条件。新增可选clearOnSubmit参数（默认仍为true，当前宿主传false），避免网络准入失败时清空受控草稿。UI所需三个类型采用本地结构接口，不引入未使用的模型SDK。IME、229、Enter/Shift Enter、16000字符、停止和会话草稿保持；图片/截图/文件上传和语音入口没有开启，maxFiles=0拒绝外部文件。原生CSS限高滚动，无内联测量或第二个输入框。

清理旧页面对全局发送按钮的尺寸覆盖，以及宿主裸textarea边框与组件库InputGroup的冲突。主题、响应式和无障碍继续沿用工作区约定，保留单一焦点边框。

## Pi真实流式链路

模型请求仍经过AI Gateway输入Block及Laya Monitor。桥接请求启用模型SSE；结构化协议只增量解码answer字符串，正确处理跨片段转义与Unicode。工具对象全部缓冲，完整JSON、可用工具名及参数验证后才交给Pi，随后继续原工具前后审核和逐次审批。没有浏览器模拟逐字动画。

Pi运行时订阅SDK text_delta，校验累计文本并保留32字符边界缓冲，避免凭据模式跨token泄漏。每条助手消息带稳定编号：answer_delta用于预览，answer是权威完整正文。主页面按编号合并，完整回答替换预览，兼容旧版无编号回答；失败/中断预览不会成为后续已完成模型上下文。

同源`/api/agent/runs/:id/events`提供NDJSON快照与增量。内部Node监听127.0.0.1，沿用设备身份、内部鉴权与会话归属；公开Python代理不暴露内部密钥。流连接断开只移除观看订阅，不取消任务。心跳、慢消费者断开、重连快照和原轮询恢复保留；旧轮询不得覆盖更新的增量序号。终态快照持久化失败/中断标记。

用户停止通过原取消接口。模型桥在客户端断开时继续排空在途上游，再释放设备租约，避免第二个任务与未结束生成重叠。刷新或浏览历史不会重复发送任务；未完成文本可在任务记录恢复，但不进入未来上下文。当前仍未启用语义输出审核。

## 详情与确认

写入/检查前的差异、参数摘要、有效期及允许/拒绝仍在正文中显示。成功工具与正常审核移入执行详情，故障时直接给用户可操作的说明。详情保留真实事件、文件、工具结果、审核与Pi原生来源能力说明，后台审计没有删除。

实际模型行为、UI夹具和设备端探测分别留证据，不把UI流式效果视作模型吞吐提升。启动和部署见operations.md。

## 聊天体验优化（2026-10-20）

输入继续直接使用 Harness PromptInput。工作模式为 Ask / Agent；回答模型为 Auto / 手动指定。Auto 触发按钮直接显示“仅本地”“允许云端”，项目工具任务同样显示“仅本地”或“允许云端”。调用范围并入模型菜单，选择允许云端时说明经审核文本及必要历史可能发送至 DeepSeek、按量计费；Agent范围贯穿服务端且绑定任务；旧请求缺省按仅本地。

桌面模型菜单使用 Radix 实际可用高度并独立滚动，搜索固定在顶部。手机使用底部 Dialog，沿用关闭、焦点恢复、键盘与主题原语。图片、附件和语音仍未开放。

Pi 未产生文字时，依据未完成的实际工具事件显示读取、搜索、检查或整理回答，并显示等待时间；不显示工具原始参数、不模拟进度百分比。长等待提示可以停止，计时本身不重复朗读。文字开始流出后等待说明消失。时间是用户等待时间，不是模型首字或吞吐指标。

普通回答与 Pi 统一使用复制、执行详情操作。失败、停止和阻断提供“编辑后重发”：仅恢复能安全取得的草稿及本轮模式、模型、项目和文件，已有新草稿时拒绝覆盖，用户主动发送后重新审核和逐次审批。被阻断原文只可从当页内存恢复，不新增敏感原文持久化。刷新后无法取得时要求重新输入，不自动重放工具。

详情先呈现本轮结果、实际模型与真实工具记录；选模/审核/标识归入高级折叠。审批差异保留原文，增加文件和增删行摘要，长差异独立滚动；允许/拒绝始终位于差异外。90秒、单次、参数及旧SHA绑定均未改变。

手机欢迎页减小上方留白；历史按已有时间分组为今天、昨天、更早，无时间信息归“其他对话”，不伪造日期或改写历史。行内重命名不切换当前对话、不影响草稿。当前没有新增置顶或删除功能。

## 侧栏与输入交互调整

会话改为紧凑单行，保留类型图标与进行中提示，完成状态供辅助技术读取。重命名收进每行的省略号菜单，鼠标悬停、键盘聚焦和触屏均可操作。历史按已有时间降序排列，未发送会话单独归为“草稿”；无有效日期的历史仍归“其他对话”。搜索同时匹配标题和未排除的本地消息正文。

侧栏顶部提供折叠按钮；折叠后保留展开、新建、搜索及工作台工具。Ctrl / ⌘ K 在聊天页聚焦会话搜索，看板仍搜索页面；搜索内按方向下键进入结果，Esc 清空搜索。Ctrl / ⌘ Shift O 新建对话并聚焦输入框。手机使用单一导航抽屉，避免与隐藏桌面导航重复挂载相同会话表单。

Harness 源组件继续使用原实现，宿主布局样式集中在 `chat-controls.css`。圆角输入面板中，上方放项目与文件标签，下方左侧是上下文和 Ask / Agent，右侧是回答模型和发送 / 停止。输入随文字增长，桌面最高 220px、手机最高 180px，并进一步受视口高度约束；长文在框内滚动。保留中文输入法、Enter / Shift Enter、字符限制、停止及全部既有模型能力。不能发送时说明原因，临时通知可关闭。

切换会话同时恢复内存中的文字、图片、已选文件、工作模式、模型和调用范围；再次点击当前会话不会清空文件。未保存草稿继续仅存当前页内存，不增加浏览器持久化。异步项目请求被接纳后，只清空原会话的已提交草稿，避免覆盖切换后输入的新草稿。新访问会话沿用当前模型和范围偏好；恢复已有草稿时使用该草稿的选择。

## 模式与模型菜单

Ask / Agent 使用与模型控件相同的 Radix Popover 原语，替代浏览器原生 select 外观。菜单显示图标、名称、用途与当前选择；支持上下方向键、Home / End、Enter 选择、Esc 关闭并返回触发按钮。展开时保留页面其余内容的读屏上下文，生成期间禁用切换，选择模式不提交任务、不清空草稿。

桌面模型菜单宽 328px，使用紧凑模型行与分组标签。移除每项重复的“可用”文字，保留勾选、未加载和不兼容状态。搜索使用圆角底色和单层细边框，避免自动聚焦时出现粗重双边框；搜索支持去除首尾空格，从搜索框按上下方向键进入结果。菜单右侧与输入工具栏的模型按钮对齐，低矮视口仍允许选项区独立滚动。

Auto 调用范围位于模型列表底部，改为“仅本地 / 允许云端”分段控件。保留文本与必要历史可能发送到 DeepSeek、按量计费的说明；项目工具模式允许云端时由Laya在9B／DeepSeek间判断，每个任务内锁模。手机保持底部面板，两个菜单均复用页面的明暗主题、关闭和焦点恢复行为。

## 本地模型和图片

回答菜单分常用、专项与备用、云端；4B、2B与决策引擎分开标识。普通Ask允许图片按钮和粘贴，展示预览、删除及本地检查状态；Agent／项目工具和云端图片不可选。图片审核失败保留编辑重发入口，不将服务故障显示为违规。详情显示真实回答模型，旧轮次名称保持原记录。

## PDF / DOCX 文字附件

输入框支持选择最多3份PDF/DOCX，发送时由设备提取并审核文字；不做OCR。附件草稿保存在页面内存，切换会话保留，刷新/离开纳入统一提醒。已完成消息只保存元数据和原问题，提取全文由设备控制；阻断消息不保存附件名称或原文。参见 [文档文字输入](document-text-input.md)。
