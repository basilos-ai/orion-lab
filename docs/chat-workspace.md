# 聊天工作台

2026-10-19 整页调整沿用现有 React、Radix、Lucide 和 Harness AI 组件，以 Cursor/Codex 的克制工作台布局作为视觉方向。

- 侧栏优先展示新建、搜索和最近会话；资源监控、模型评测、AI Gateway 放在底部工具区。跨工具链接在新标签打开，当前草稿仍留在聊天页。
- 单一顶部栏显示会话名称、设备状态、执行详情和对话操作。重命名、Markdown 导出及外观说明收在对话菜单中；弹层关闭后回到稳定的触发按钮。
- 空会话将欢迎文字、输入区和三个文本示例连成一个整体。示例只填充草稿，不自动调用模型。
- 有消息时独立滚动消息区，输入区保持可达；用户消息与助手正文分开呈现，保留实际模型、执行记录、复制和选模反馈。
- Markdown 保留列表序号；代码与宽表格在自身区域滚动，并能用键盘聚焦。代码复制仅复制代码正文。
- 宽屏执行详情为侧面板，1180px 及以下为对话框；760px 及以下用导航抽屉。亮暗主题通过聊天专用语义 token 同时覆盖主页面和 Portal 弹层，看板保留原有配色。

`ChatHeader` 是聊天业务组件，`AppShell.header` 只是宿主插槽；共享 Button、Input、Dialog、Popover、Textarea 不增加业务行为。参考 Harness 的 Admin Dashboard V2 会话结构及 AI Conversation/Message/PromptInput 组合方式，未引入额外依赖或复制模板的演示业务数据。

保留模型/scope 请求格式、AI Gateway 输入 Block、失败轮次过滤、流式显示、停止、IME 与 Shift+Enter、会话存储键和内存草稿机制。刷新不会持久保存未发送草稿。资源采样和模型后端不属于本次改动。

验收包含 1440×900、900×900、390×844、320×740 的亮暗主题空会话与有消息状态，以及长历史、宽代码/表格、会话搜索与草稿切换、菜单/弹层回焦、重命名、导出、导航收合、资源入口和原输入区回归。浏览器模型响应使用隔离样例；上线核验仅允许 GET/HEAD。证据与发布记录在项目根目录的 `部署记录/聊天工作台优化-20261019/`。
