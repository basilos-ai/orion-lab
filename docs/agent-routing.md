# Agent动态选模

## 可选Auto决策模型

决策模型与回答模型分开。新界面默认后摩Qwen3.5-2B，可选择后摩4B或Laya；GLiNER不接入。decision_engine是固定枚举laya、qwen35-2b-houmo、qwen35-4b-houmo。旧客户端省略字段继续使用Laya。选择不赋予云端或工具权限，27B继续仅普通聊天手动使用。

普通聊天保留图片、长上下文和能力保护规则，规则不能确定时调用所选分类器。Qwen输出A适用轻量回答，B/C使用9B，既有获准云端规则保留。项目Ask与Agent允许云端时A使用9B、B/C使用DeepSeek；仅本地或只有一个合法候选时跳过多余判决。Laya保留原门限，Qwen使用约束JSON类别，不伪造概率。

任务内锁定引擎、回答模型和范围，缓存绑定引擎和版本，工具循环不重新选模。Monitor复用原判决，界面称为选模Monitor，外部原策略无需改名。两款Qwen服务仅回环，通过固定unit按需管理。同卡仅保留一款决策模型，加载受设备gate保护；27B已加载时不会自动卸载它，用户手动加载27B前才释放决策服务。

Qwen关闭思考，输出24token，严格校验JSON、重复键、完成原因与cache_n=0；异常显式回退9B。2B热推理预算1.5秒，4B为2.5秒，冷加载另有30秒就绪等待，每个服务控制命令上限15秒。长背景显式标记截断并保守路由。下文Laya参数仍适用于旧客户端与选择Laya的请求。

Agent与带项目的Ask共用路由。每条新任务在输入审核后判决一次，候选为本地9B和DeepSeek；工具循环内锁定模型。2B不进入工具路由，27B继续通过普通聊天手动加载。

| model / scope | 行为 |
| --- | --- |
| auto / local | 使用9B，跳过二选一；9B未加载则停止 |
| auto / hybrid | 两路可用时由本地Laya判决；只有一路可用时注明可用性原因 |
| standard / 合法范围 | 固定9B，不运行Laya |
| cloud / hybrid | 固定DeepSeek，仍检查额度 |
| cloud / local或缺省 | 后端拒绝，不扩大范围 |

scope缺省local，贯穿前端、Node、Python和服务端任务lease，模型调用逐轮检查。输入框改变范围只影响下一条任务。允许云端包括经审核的问题、必要历史、选定文件片段和获准工具结果，不自动外发整个项目。

Laya单问分类为A常规且目标明确、B复杂、C目标不明确。只有A达到本地门限且材料未截断时选9B，否则使用获准云端。当前分数门限0.40、领先间隔0.10，是开发集选择的实验参数，不是经过校准的成功概率。路由对表述敏感，可能把简单任务过多送到云端，不能宣称它能准确判断所有任务。

HTTP预算500ms、总预算800ms、分类锁等待40ms；异常或非法分数明示回退9B。缓存60秒、最多128条，绑定服务端身份、项目、范围、完整上下文和版本；模型可用性与额度重新检查。Monitor复用判决，不重复推理。

仅本地且9B未加载时停止，不自动卸载27B或切卡。允许云端且9B未加载时可用DeepSeek。Auto遇到云端未配置或额度不足时明示回退9B；手动DeepSeek不可用则停止。开始执行后不跨模型重放，不重复消费审批。

决策记录包含decision_id、版本、来源、范围、类别、分数、耗时、缓存及回退原因。Python分别记录agent_decision、agent_dispatch、agent_gateway、agent_usage，用真实派发和Gateway回执核对云端次数。浏览器不能指定缓存身份，Laya不能提供模型地址或工具权限。

输入Block、流式answer、工具JSON完整验证、三阶段策略桥接与一次性审批保持；不修改AI Gateway源码，不冒用原生Pi来源。模型生成格式不合规时仍拒绝执行，流程结束与任务正确率分开统计。

看板 `#agent-routing` 独立读取 `assets/agent-routing.json`，不覆盖原生成测试data.json与附件。空示例不含设备成绩；部署者注入自己的路由集、固定9B／固定DeepSeek／Auto同题结果和验收。保留失败、格式错误和缺失费用，不以零代替未知。真实设备证据留在仓库外。
