# 资源监控趋势纵轴自适应

日期：2026-10-29。用户要求低数值趋势的纵轴上限跟随已出现的最大值。本次只调整前端图表比例；原始数值、采样接口和刷新行为保留。

## 行为

- CPU、可用内存、温度的概览小趋势图及 CPU / 内存历史图，按当前可见历史中的有效峰值确定纵轴。
- 保留 0 基线，峰值上方留约 20% 余量，再取整为易读刻度，使用四段、五个刻度。取整后实际余量可能大于 20%。
- 例如 CPU 峰值 2.8% 对应 0–4%，7% 对应 0–10%；全零或峰值不足 0.83 时最小量程为 0–1。正常 CPU 高占用时上限最多 100%；异常越界观测不会被静默裁掉。
- 可见历史窗口内的峰值决定范围；新峰值进入后放大，旧峰值移出后缩小。整齐刻度避免每个小变化都改变上限。
- 缺失、非有限数值不参与峰值计算；原来的缺失 / 间断不连线、没有历史时不画趋势继续保留。
- 磁盘、核心占用等表达容量或百分比的进度条继续按原物理口径显示。
- 历史图说明增加“纵轴自适应”及单位，避免误把低刻度上限理解为容量上限。
