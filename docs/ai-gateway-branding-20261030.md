# AI Gateway 名称统一

2026-10-30 按项目要求，将侧栏控制台入口、隐私说明、输入保护提示、执行详情和项目说明中的展示名称统一为 **AI Gateway**。控制台仍指向当前部署地址的 13000 端口。

旧服务及已保存会话可能返回旧名称。前端只在系统错误、状态说明与执行详情的展示层转换名称，不改写用户消息、模型回答或保存的原始回执。浏览器回归覆盖阻断提示、刷新恢复和错误详情中的兼容显示。

现有服务标识、配置键、适配器包名和 HTTP 协议头继续兼容；第三方代码及历史核验数据保留原样。两个前端入口使用同一生产构建，发布采用新目录、哈希校验与原子软链接切换；保留上一版入口供回滚。

验证：类型检查、JavaScript/Python 单测、源码边界检查、完整构建及浏览器回归；设备验证记录位于项目外层的部署记录中。
