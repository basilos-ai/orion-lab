# 统一会话工作区

聊天与 Pi 使用同一个 React AppShell、会话列表、消息时间线和输入框。`#chat` 为统一入口；旧 `#agent` 链接只把新草稿切到 Agent，不发送请求。会话由 `?conversation=<id>` 定位。

| 下一轮设置 | 执行方式 | 模型 |
| --- | --- | --- |
| Ask，无项目 | 原 NDJSON 流式问答、Laya 与保护规则 Auto | Auto、2B、9B、DeepSeek；27B 手动加载 |
| Ask，选择项目 | Pi 只读文件工具 | Auto按scope使用本地9B或Laya动态判决；9B／DeepSeek手选 |
| Agent，选择项目 | Pi 文件工具，修改与检查逐次审批 | 同上 |
| Agent，未选项目 | 提示先选择授权项目 | 不执行 |

工具任务中的 2B、27B 不可用，并说明原因。不兼容模型不会被暗中替换。首版只授权 demo；选择器通过后端清单提供最多 5 个相对文件路径，不接受任意主机路径。图片保护尚未开放。

## 会话和上下文

共享契约为 Conversation → CompletedTurn / ExecutionRun。每轮保存 Ask / Agent、模型、scope、项目与文件快照；修改输入框设置不会改变历史。普通聊天完成时由 Python 网关通过回环接口证明完成并保存 prompt / answer；浏览器不能调用完成接口。Pi 只有 completed 且有回答时才保存已完成轮次。失败、阻断、取消、未批准修改、系统提示及完整工具日志不进入下一轮会话上下文。

上下文取最近最多 6 个完整轮次，总计最多 3000 字符，按时间顺序传给两种路径。Pi 根据当前问题长度缩小历史预算，附加文件总预算约 1800 字符；截断会记入事件。历史与文件标注为背景及不可信数据，整体再次审核，实际模型调用仍经过 AI Gateway。文件中的指令不能提升工具权限。后续工具响应仍受 8192 字符审核预算约束。

私有 `conversations/<id>.json` 为 0600，以网关按授权设备地址派生的 HMAC principal 校验归属。它沿用设备白名单授权，不是多用户账号系统；同一授权设备的浏览器共享设备级归属。变更授权项目需要新会话。审批摘要绑定 conversation、turn、run、工具与参数，90 秒有效、一次消费，写入仍核对旧文件 SHA。

旧 `o6n-controlled-sessions-v3` 只读取、保持原值。新 `orion-workspace-sessions-v1` 幂等合并旧聊天，不批量上传。旧独立 Pi run 各自映射为历史会话，不推断关联。旧会话缺少服务端记录时，请在当前任务中补充背景；接续以本版本记录的完成轮次为准。旧键可供前端回滚读取，新版会话需保留新索引与服务端目录。

## 时间线与运行状态

普通问答保留 Markdown 与流式回答；Pi 使用原轮询事件，按调用 ID 把工具开始、完成、错误合为一张卡。写入审批显示真实前后内容、原行号/新行号及增删行；不输出虚构检查结果。审批始终在消息内展示，手机不依赖侧栏。

详情默认关闭，提供本轮、文件、更改三类；文件来自显式选取及已审核读取结果，更改保留提议记录。批准不保证写入成功，实际结果看工具完成事件。执行时可查看其他会话或准备草稿，不能并发提交；显示全局忙碌和返回执行会话。取消等待执行与门锁释放，不声称撤销已经完成的写入。刷新恢复待审批；服务重启后未完成任务标记取消，不自动续跑。

AI Gateway 输入 Block、Laya Monitor、Pi 策略桥接保持原规则，原生 Hooks 不支持 Pi 的能力缺口仍明确显示。未修改 AI Gateway 源码或冒用来源。流式输出未启用语义审核。

## 验证与开源

`npm test` 覆盖迁移、轮次顺序、预算、归属、幂等完成、差异行号及真实 Pi SDK 携带历史的工具闭环。`npm run test:browser` 覆盖跨路径的同一会话、刷新审批、历史浏览，API 为夹具；设备推理及真实审批另留私有记录。MIT 源码不含这些记录、真实聊天、权重或凭据。启动与回滚见 [operations.md](operations.md)。
